# Context

Standing facts about what is being taken to market. Gates read this table, so
leave a value blank rather than guessing at it.

`product_state` is one of `none`, `prototype`, `mvp`, `live`. It is load-bearing
rather than decorative. The market-problem map drops its third axis when there
is no product, because ease of implementation is unknowable before one exists
and scoring it anyway manufactures false precision. That rule cannot be computed
without this field, and a blank one is reported rather than guessed.

`who_we_think_buys` is a hypothesis until the ledger says otherwise.

| field | value |
|---|---|
| product_state | mvp |
| what_we_sell | Lumen Freight — dock-scheduling software for regional less-than-truckload carriers |
| who_we_think_buys | the terminal operations manager at a 20-to-80 door regional LTL carrier |
| current_alternative | a shared spreadsheet plus a phone tree run by the dock supervisor |
